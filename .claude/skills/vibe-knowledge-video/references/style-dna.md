# 风格基因：Vibe 知识短片

> 这份文件是第一步“视频制作学习”的产物：从 5 个参考视频里拆出来的风格规则。
> 写脚本时读第 2 节，写画面时读第 3、4、6 节。**不要再去重新分析参考视频**，结论都在这里。

## 1. 一句话定义

**暗场 + 衬线字 + 一个会不断变形的视觉隐喻 + 字幕代替配音 + 钢琴 BGM。**
观感接近一部 2 分钟的纪录片片头，或者博物馆里的展陈：克制、安静、有仪式感，信息密度靠字幕和画面的配合，不靠快剪。

## 2. 叙事结构（写脚本时照这个走）

| 时间 | 段落 | 参考原句 |
|---|---|---|
| 0–6s | **钩子**：用第二人称写一个日常处境、一个反问，或者一道填空 | “好友聚会结束，你是否感到空荡？过完年，热闹散去，你是否感到悲凉？”（R1）<br>“一千米跑到第二圈，喉咙里泛起血腥味，你是否只想停下来？”（R2）<br>“为什么要学习？为什么上班？为什么努力？……然后呢？”（R3）<br>“床前明月 __ ——你一定猜到了下一个字。”（R4）<br>“骰子落下之前，谁也不知道答案。运气，能被计算吗？”（R5） |
| 6–9s | **点题**：把日常体验接到一个“有名字的大概念”上 | “那么恭喜你，你撞上了尼采哲学的核心：”<br>“如果是，那么恭喜你，你发现了叔本华的——”<br>“这一切，都没有意义。这就是虚无主义。” |
| 7–10s | **标题卡**：粒子聚成大标题，配外文副题和出处 | 「权力意志」/ 尼采《查拉图斯特拉如是说》<br>「运气的形状」/ DE FORMA FORTUNAE / 人类如何把偶然写进数学 |
| 主体 | **观点 → 隐喻**，每个观点一个视觉隐喻，并挂上历史锚点（年份、地点、书名、原话） | “热闹，只是一层滤镜。”→ 暖色照片碎掉（R1）<br>“1494 · 威尼斯 · 帕乔利《算术大全》”→ 记分牌 50 : 20（R5） |
| 高潮 | **反转**：画面要有一次“质变”，比如黑转白、碎裂、光爆 | R3 在“上帝已死”时整屏从黑底翻成白底 |
| 结尾 | **回扣开头**：回到开场的画面或问题，给出新答案，留一句能截图传播的金句 | |

**节奏（实测）**：
- 每条字幕停留 2–3.5 秒，阅读速度约每秒 6–7 个字。引擎按字数自动算时长。
- 标题卡出现在第 7–10 秒。
- 30 秒内的**硬切只有 0–2 次**（实测：R1 2 次，R2 1 次，R3 1 次，R4 1 次，R5 0 次），而且都落在戏剧性时刻：进标题、碎裂、黑白反转。**其余时间画面靠连续变形推进**，不靠切镜头。
- 全长 1.5–3 分钟最常见，深度选题可以做到 5 分钟（R4）。

## 3. 视觉语法

### 3.1 画面
- **暗场**：背景是近黑色，中心偏上有一团柔光，四周压暗角；全屏飘着细微的浮尘，叠一层胶片颗粒。
- **一个光源当焦点**：吊灯（R1）、聚光（R3）、发光的点（R2、R4）。观众的视线跟着光走。
- **元素少，留白多**：一屏只讲一件事，主体居中。
- **画法**有三类，同一个视频只选一类：
  1. 扁平剪影插画（R1：沙发、窗外城市、人物剪影）；
  2. 细线几何 / 线描（R2 透视跑道，R3 的玫瑰窗和星座点阵，R4 的进度线）；
  3. 拟物小道具（R5：骰子、羊拐骨、硬币、纸张）。
- **小人**：用象形符号式的小人（圆头加粗线身体），不画写实人物。

### 3.2 运动词汇（engine-api.md 里都有对应组件）

| 动作 | 参考 | 用在哪儿 |
|---|---|---|
| 粒子聚合成标题 | R1/R4/R5 | 标题卡（引擎自动做） |
| 点阵标题（星座感） | R3 | `titleStyle: "dots"` |
| 逐字打出的字幕 | 全部 | 默认字幕效果 |
| 线条描出（stroke draw） | R2/R3/R5 | 跑道、玫瑰窗、轨道、命运之轮 |
| 化为灰烬（dissolve） | R1/R3 | 人群、物体“消失 / 失去意义” |
| 玻璃碎裂（shatter） | R1 | “滤镜碎了”“幻象破灭” |
| 竖排滚字（slot） | R4 | 候选字 / 可能性在滚动 |
| 数字滚动（counter / 年份） | R5 | 年份、比分、概率 |
| 红色印章砸下（stamp） | R5 | “中断”“战书”“文献”等关键判词 |
| 涟漪（ripple） | R2 | 起点枪声、到达终点 |
| 推镜头（camera push） | R1/R2 | 情绪加深 |
| 黑白反转 + 闪光（theme 切换） | R3 | 高潮、观念崩塌 |
| 背景巨型外文铭文（bgWord） | R5 | ALEA IACTA EST，营造古典感 |

**禁用**：3D 翻页、旋转飞入、抖音模板式转场、无缘无故的镜头抖动、弹跳卡通动效。

### 3.3 字体与排版
- 中文一律用**思源宋体 / Noto Serif SC**；外文、年份、数字用 **Cormorant Garamond**（斜体用来写书名、原文、人名），数字用等高数字（lining）。
- 层级（以 1920×1080 为准）：

| 元素 | 字号 / 字重 | 位置 |
|---|---|---|
| 标题卡主标题 | 150px / 900，字距 .14em | 正中 |
| 钩子大字（headline） | 62px / 700 | 上方居中，最多 3 行 |
| 静谧大字（center，R4 式） | 68px / 300，字距 .18em | 正中 |
| 底部字幕 | 42px / 500 | 底部居中，单行 ≤ 20 字 |
| 英文对照 | 字幕字号的 0.56 倍，斜体，灰色 | 中文下方 |
| 章节标签 | 32px / 800 + 19px 斜体外文 + 发丝线 | 左上 |
| 账号水印 | 17px，字距 .3em，细框 | 右上 |

- **高亮**：每句最多 1 个关键词，用主题强调色、加粗、带微光。写法是在脚本里用 `**词**` 包起来。
- 标点用全角；引号用中文引号 `“”`。

### 3.4 纪录片“外壳”（这一层让人觉得专业）
始终在画面上的信息层：
- 左上：**章节标签**，标题卡之后自动出现，例如「最速降线 / Brachistochrone」；
- 右上：**账号水印**（细框）；
- 右上：**文献出处**，外文斜体书名、中文书名、作者和年份，旁边盖一枚小红印「文献」；
- 左上：**年代牌**，大号年份（数字滚动出现）加地点和人物。

|---|---|---|---|---|
| `night` | 午夜蓝 | 琥珀暖光 | 情绪、人生、心理、孤独 | R1 |
| `crimson` | 黑红 | 玫瑰红 + 白线 | 意志、奋斗、冲突、身体 | R2 |

## 5. 声音

- **没有配音，字幕就是旁白。** 频谱分析确认 5 个视频都没有人声，所以不需要 TTS。
- **BGM**：R1、R2、R3、R5 用的是**同一首**钢琴主导的曲子（色度相似度 0.95–1.00，约 112 BPM，第 15 秒和第 17 秒左右有段落变化）。两个不同账号用同一首，说明它是抖音曲库里的热门曲。R4 用的是另一首氛围铺底加拨弦的曲子。
  → **做法**：我们渲染出的 MP4 只带音效。发布时在抖音里点参考视频右下角的音乐，“使用同款”，把 BGM 加上，原声（音效）音量调到 50–70%。这样音乐版权由平台曲库覆盖。
- **音效只给画面里“真实发生”的关键动作**：发令枪和欢呼（R2）、滚字的嘀嗒声（R4）、彗星划过的嗖声（R4）、标题出现时的闪光音。密度上限大约 3–5 秒一个，不要满屏都有音效。
- 以下音效引擎会自动加，不用手写：标题卡（shimmer）、盖章（stamp）、碎裂（crack + shatter）、化灰（whoosh）、色调反转（boom）。

## 6. 质量自检（出联系表后对照）

- [ ] 前 3 秒就有钩子，第 10 秒之前出现标题卡
- [ ] 每个节拍的画面都有状态变化，没有“字幕在走、画面干等”的情况
- [ ] 一屏只有一个视觉焦点，主体不撞字幕安全区（底部 880–1010px、上方大字区 150–430px、四个角的外壳）
- [ ] 每句字幕最多一个高亮，单行不超过 20 字
- [ ] 至少有一处历史锚点（年份、地点、书名或原话），而且是可以查证的事实
- [ ] 全片最多两次硬切，并且都在戏剧性时刻
- [ ] 结尾回扣开头
