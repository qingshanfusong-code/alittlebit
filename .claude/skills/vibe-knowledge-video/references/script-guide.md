# 第二步：选题 + 文案 + 分镜 → script.json

产出物只有一个文件：`studio/videos/<英文短名>/script.json`。它同时是**文案**（`say`）、**节奏**（自动时长和 `hold`）和**分镜**（`v` 画面备注）。第三步写画面时只看它。

## 1. 选题

好选题需要同时满足 4 条（每条 0–2 分，总分 ≥ 6 再做）：

1. **有名字的大概念**：X 主义、X 论、X 定理、X 效应、X 悖论。观众会搜，也愿意收藏。
2. **能接上一个日常体验**做钩子：跑步想放弃 → 权力意志；聚会散场 → 悲观主义。
3. **有历史锚点**：人物、年份、地点、原著，是可以查证的真事和原话。
4. **一个视觉隐喻能贯穿全片**：跑道、骰子、填空的诗句、滑梯上的两颗球。

账号「听劝的拉格朗日」（数学、物理、思维模型）的题库方向（只是示例）：
最小作用量原理 · 拉格朗日乘数（约束下的最优）· 熵与时间之箭 · 贝叶斯（“听劝”的数学：用证据更新信念）· 纳什均衡与囚徒困境 · 蝴蝶效应与混沌 · 哥德尔不完备 · 图灵停机问题 · 布雷斯悖论 · 大数定律 · 帕斯卡赌注 · 芝诺悖论 · 傅里叶变换。

## 2. 文案公式

```
钩子（第二人称日常处境 / 反问 / 填空，0–6s）
  → 点题（“那么恭喜你，你撞上了……” / “这就是……”）
  → [标题卡]
  → 3–5 段「观点 → 隐喻 → 历史锚点」
  → 反转（认知翻转一次，配一次画面质变）
  → 回扣开头 + 一句金句（+ 可选：一个留给评论区的问题）
```

写作规则：
- **一句一个意思**。底部字幕单行 ≤ 20 字；大字（headline）每行 ≤ 12 字，最多 3 行。
- **每句最多 1 个 `**高亮**`**，只高亮“关键词”，不高亮整句。
- 用短句和逗号断开来制造节奏：“曲终人散，滤镜碎了。”比“当聚会结束时我们会发现热闹只是表象”好得多。
- **史实零容忍**：年份、地点、书名、原话必须是你确定的。不确定就不写，或者改成更泛的说法。引用原话时，在 `en` 里放原文（拉丁文、德文、英文斜体）。
- 不要用“家人们”“绝绝子”这类口播腔，也不要 emoji。语气要像纪录片的旁白。
- 结尾不要“关注我”，用金句或问题收尾。

## 3. script.json 规范

```jsonc
{
  "meta": {
    "title": "最速降线",           // 项目名（也用作渲染时的标题）
    "theme": "abyss",              // night | crimson | mono | abyss | gilt（见 style-dna 第 4 节）
    "brand": "听劝的拉格朗日",      // 右上角水印，标题卡下方显示“— X 出品 —”
    "fps": 30,
    // 可选：subPos 默认字幕位置 bottom|headline|center；titleStyle "dots"；chapter false 关闭章节标签；
    //       chapterStyle "bracket" 显示成【标题】；bgm "music.mp3" + bgmGain 0.35（一般不用，BGM 在抖音里加）
  },
  "beats": [
    {
      "id": "q1",                   // 唯一，第三步和改稿时都用它定位
      "scene": "race",              // 场景名；不写就沿用上一个；连续相同的节拍归为同一个场景
      "say": "从 A 滑到 B，\n哪条路**最快**？",   // 字幕：\n 换行，**…** 高亮
      "pos": "headline",            // bottom（默认）| headline（上方大字）| center（正中静谧大字）
      "en": "Which path is fastest?",  // 可选：英文 / 原文对照
      "hold": 1.2,                  // 字幕读完后再停几秒（留给画面动作）
      "v": "两点 A、B；先描出直线，再描出下垂的曲线"   // 分镜备注：这一拍画面上发生什么（引擎忽略）
    },
    { "id": "title", "type": "title", "title": "最速降线", "latin": "Brachistochrone", "sub": "约翰·伯努利 · 1696" },
    {
      "id": "c1", "scene": "letter", "say": "1696 年，约翰·伯努利向全欧洲**下战书**。",
      "era":  { "year": 1696, "place": "格罗宁根 · 约翰·伯努利" },              // 左上年代牌（数字滚动）
      "cite": { "la": "Acta Eruditorum", "zh": "《博学学报》", "note": "1696 年 6 月刊" },  // 右上出处 + 红印
      "sfx": "whoosh",              // 可选：节拍开头的音效；或 [{ "name": "tick", "at": 0.5, "gain": 0.6 }]
      "v": "羊皮纸信笺浮现，盖红章「战书」"
    }
  ]
}
```

> 上面用 jsonc 只是为了加注释，**真正的 script.json 是严格 JSON，不能写注释**。

时长规则：
- 有字幕时自动算：`0.8 + 0.13 × 字数` 秒，限制在 2–6.5 秒之间，再加 `hold`。
- 只有画面、没有字幕的节拍要写 `"dur"`（默认 2 秒）。
- 标题卡默认 4.6 秒。
- `era` / `cite` / `chapter` 会一直保留，直到后面某个节拍把它改掉，或者设成 `null` 关掉。
- `"theme": "paper"` 写在某个节拍上，就会在那一拍闪白并反转成白底（高潮用）；之后在另一个节拍上写 `"theme": "abyss"` 可以切回来。
- `"enter": "cut"` 写在某个场景的第一个节拍上，表示硬切进入（默认是 0.8 秒交叉淡化）。全片最多用两次。

## 4. 交付前自查（第二步结束时）

1. 运行 `node tools/render.mjs videos/<名> --timing`，看总时长和每拍时长。这是纯文本，不出图，很省。
2. 对照 style-dna 第 2 节：第 10 秒前出现标题卡吗？有反转吗？结尾回扣开头了吗？
3. 每个节拍都有 `v`，每个场景都有一个**贯穿的视觉隐喻**。
4. 把文案（按节拍列出 `say`）和时长表一起给用户确认。**文案定稿之前不进入第三步**。改文案几乎不花 token，改画面很贵。
